# Project Expert Web — учебный прототип

Независимое браузерное приложение для учебного планирования проектов. **Не является портом, копией или официальной версией Project Expert 8.02.** Исходный Windows EXE не используется.

## Быстрый запуск

Откройте `index.html` в браузере. Никаких зависимостей, сборки или сервера не требуется.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Загрузите **содержимое** этой папки (`index.html`, `app.js`, `style.css`, `README.md`) в корень репозитория.
3. В `Settings → Pages → Build and deployment` выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`.
4. После публикации откройте ссылку Pages, которую покажет GitHub.

## Возможности

- Редактирование работ, зависимостей, длительности и затрат.
- Метод критического пути (CPM), ранние и поздние сроки, полный резерв.
- Диаграмма Ганта.
- Упрощённые денежные потоки, NPV, простой срок окупаемости.
- Отчёт для печати / сохранения в PDF средствами браузера.
- CSV-экспорт работ, JSON-импорт/экспорт проекта, автосохранение в localStorage.

## Ограничения

- Файлы `.PEX` оригинального Project Expert **не открываются**. Их формат требует отдельного изучения и реализации конвертера.
- Связи работ только «окончание–начало», без лагов. Дни календарные.
- NPV использует месячную ставку `годовая ставка / 12`, без налогов и инфляции.
- Финансовая модель демонстрационная и не воспроизводит алгоритмы оригинальной программы.
- Данные localStorage привязаны к браузеру и домену. Для переноса используйте экспорт JSON.

## Авторство

Учебный прототип для работы в Linux и браузере. Код распространяется как самостоятельная реализация, без включения файлов оригинальной программы.
